# GoreeCloud Feeds Shared Compatibility

## Current state

No shared package, public API, package version, or compatibility matrix exists.

## Future compatibility responsibilities

When a shared package is implemented and distributed, compatibility documentation should define:

- supported consumers;
- package/runtime versions;
- dependency requirements;
- breaking-change rules;
- deprecation behavior;
- migration requirements;
- release provenance; and
- exact validation evidence.

Shared-library compatibility must not be confused with GoreeCloud Feeds client/server protocol compatibility. Protocol authority belongs in GoreeCloud/feeds-protocol.
