# GoreeCloud Feeds Web Branding

Official product component name: **GoreeCloud Feeds Web**  
User-facing product identity: **GoreeCloud Feeds**  
Repository: GoreeCloud/feeds-web

The web client should present itself to users as GoreeCloud Feeds rather than exposing the repository name as a product brand.

## Design system

Live GoreeCloud GitHub state identifies Glaze UI V1.6.0 as the current Official Stable consumer target.

Future implementation must use the applicable current Glaze UI authority and still complete Feeds-specific rendered, responsive, accessibility, performance, reduced-motion/transparency, localization, rollback, and product acceptance. A shared design-system Stable state does not automatically make this application conformant.
