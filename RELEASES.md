# GoreeCloud Feeds Releases

## Current release state

There is currently no verified GoreeCloud Feeds release, release candidate, production deployment, or Stable version.

The initial repositories are project foundations only.

## Release documentation boundary

Future release records should identify, as applicable:

- exact source revisions;
- component versions;
- protocol version and compatibility;
- build and test evidence;
- packaged artifacts and digests;
- migration requirements;
- upgrade and rollback behavior;
- security and privacy validation;
- deployment boundary; and
- production acceptance evidence.

A merged pull request or default-branch commit is not itself a release.

## Versioning

No product-wide release versioning scheme or stable protocol version has been established yet. Versioning should be selected before the first distributable release and coordinated with `feeds-protocol` when compatibility boundaries are involved.
