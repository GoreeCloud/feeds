# GoreeCloud Feeds Releases

## Current release state

There is no verified GoreeCloud Feeds release, Release Candidate, production deployment, or Stable version.

The monorepo contains Development source foundations only.

## Release documentation boundary

Future release records should identify, as applicable:

- exact monorepo source revision;
- component and artifact versions;
- protocol version and compatibility;
- build and test evidence;
- packaged artifacts and digests;
- database and protocol migration requirements;
- upgrade and rollback behavior;
- security and privacy validation;
- deployment boundary; and
- production acceptance evidence.

A merged pull request or default-branch commit is not itself a release.

## Versioning

No product-wide Stable release versioning scheme or Stable protocol version has been established. Components may retain distinct artifact versions where technically justified while sharing one source revision and coordinated release evidence.
